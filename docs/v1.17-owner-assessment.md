- lib/landEvaluationExcel.js 的 parseReportText、buildLandEvaluationExcelBuffer 原先只擷取全文、硬截四案和三組優劣勢。獨立 owner_brief 以版本驗證，仍用原母版；依實際案例與段落數移列重建合併，原相容路徑保持。

## 遷移與回復

20261111100627_guard_report_working_revisions.sql 只新增 reports 的更新防護、版本檢查函式；不改欄、不回填、不刪除、不改 RLS。先在隔離的 PostgreSQL／Supabase 驗證舊報告可儲存、受控 RPC 及一次性 token 同交易、舊版本競爭拒絕、授權與既有讀回核對，再執行 production migration。先部署相容版再啟用使用者操作。沒有 migration，人工鎖定儲存會停止。已建立人工值後，回退程式可保留 trigger 與原資料，使不認識工作值的舊版不能覆蓋已鎖定案件；需要撤除保護時先匯出並核對人工值，再由管理員獨立遷移：

```sql
drop trigger if exists land_guard_working_revisions on public.reports;
drop function if exists public.land_guard_working_revisions();
drop function if exists public.land_working_guard_version();
```
