# 地號定位工作流（2026-10-05）

## 已實作

- 依完整縣市、鄉鎮市區、地段／小段及母號、子號，查詢 NLSC 公開 ListCounty、ListTown、ListLandSection 清單。
- 精確匹配官方地段名稱，不使用模糊比對、地段中心、門牌或人工猜測座標。
- 母號、子號各補4碼；4碼地段+8碼地號形成官方 goland 使用的12碼宗地識別碼。
- 支援同縣市、同鄉鎮多地段及多筆地號；缺漏、重複、不明地段或無法完整解析的輸入阻擋啟動。不支援跨鄉鎮混合輸入，須分案。
- 自動調研按鈕先開啟空白分頁以保留使用者手勢，核對識別碼後將本案代碼與官方地籍／航照查詢連結加入完整提示詞。
- 官方清單受阻時不產生推測定位；保留原調研流程及明確核實規則。
- Excel 基地区域圖欄明示待取得官方宗地圖，附本案官方查詢連結；不沿用歷史圖。

## 尚未完成及驗收界線

公開清單只能核對行政及地段代碼，不能驗證宗地存在，也不提供本案幾何。API 明確返回 `parcel_existence_verified=false`、`geometry_verified=false`。官方 WEB_005 goland 文件說明可定位及著色宗地；本次驗證瀏覽器中官方圖臺只顯示頁首及空白地圖，重載和直接進入其內層頁後仍未取得可核實的宗地。因此尚未完成自動圖像取得、宗地範圍核实及 PDF／Excel 圖像套入。不得宣稱完整地圖鏈路已驗收。

取得官方宗地圖後仍須核對圖內宗地身分、全部地號、相鄰位置、比例與資料日期，才可建立位置證據；這是系統核實，不要求使用者例行重新定位。只有輸入缺漏、官方查無宗地或來源衝突才需補充。

免費官方圖臺與需申請的 CAD 座標／地籍資料服務是不同入口。不得提取圖臺私有金鑰或繞過申請限制來取得幾何；不加入額外付費 API。
